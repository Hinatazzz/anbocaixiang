<h2>开篇速查：风险阶梯 与 两个分类轴</h2>
<div class="key"><b>风险阶梯（从低到高）</b>：货币 R1 &lt; 债券 R2~R3 &lt; 混合 R3~R4 &lt; 股票 R4~R5 / QDII / FOF（后三者看实际仓位）。REITs 单独算、介于股债之间。</div>
<div class="box"><span class="k">两个分类轴，别搞混</span>：
<p><b>① 基金类型</b>=买什么大类资产 → 货币 / 债券 / 混合 / 股票 / QDII / FOF（看名字里的类型词）。</p>
<p><b>② 投资方向</b>=在大类里具体押哪条线 → 宽基 / 行业 / 主题 / 因子 / 区域 / 策略（看名字里的特征词）。</p>
<p>举例：<code>中欧医疗健康混合A</code>——「混合」是<b>类型</b>，「医疗健康」是<b>方向</b>。</p></div>

<h2>一、基金份额类别：A / C / I / D / B / E / H / Y</h2>
<p>同一只基金常发多个份额，<span class="k">底层买的东西完全一样</span>，只差收费方式与渠道。看末尾字母就知道。</p>
<ul>
  <li><span class="lab">A 类（前端收费）</span>：买入时一次性收「申购费」，之后不再收销售服务费，持有越久成本越低 → <span class="arrow">适合长期（&gt;1~2 年）</span>；多数基金持有约 1~2 年是 A/C 成本临界点，超过就 A 更省。</li>
  <li><span class="lab">C 类（销售服务费）</span>：免申购费，但每天从净值扣「销售服务费」（年化约 0.2%~0.8%）→ <span class="arrow">适合短期（&lt;1 年）</span>或拿不准持有多久。</li>
  <li><span class="lab">I 类（机构类）</span>：机构 / 大资金专属，起购高（常 100 万起），费率最低 → 普通人一般买不到。</li>
  <li><span class="lab">D 类（直销类）</span>：官网 / APP 直销或特定平台定制，费率常比代销（支付宝）更便宜。</li>
  <li><span class="lab">B 类（后端收费）</span>：买入不收、赎回时收，持有越久越低至免收 → 现已少见。</li>
  <li><span class="lab">E 类（互联网类）</span>：互联网 / 特定平台销售，常见于指数基金，费率低。</li>
  <li><span class="lab">H 类（港股通 / 互认）</span>：内地香港互认基金、或港股通相关份额。</li>
  <li><span class="lab">Y 类（养老金）</span>：个人养老金账户专属，享税优，仅养老金账户可买。</li>
</ul>

<h2>二、基金类型六大类总览（选基第一层）</h2>
<ul>
  <li><span class="lab">货币基金（R1）</span>：只买超短期高等级货币工具，不投股票长期债；T+0 快赎限 1 万 + T+1；无申赎费；年化 1.5%~2.5% → 活钱 / 备用金。</li>
  <li><span class="lab">债券基金（R2~R3）</span>：80% 以上买债券；纯债 / 二级债（固收+）/ 可转债；年化 3%~7% → 稳健理财 / 半年以上。</li>
  <li><span class="lab">混合基金（R3~R4）</span>：股债灵活 0%~95%；偏股 / 偏债（固收+）/ 平衡 / 灵活配置 → 想让经理择时。</li>
  <li><span class="lab">股票基金（R4~R5）</span>：股票 ≥80%；被动指数 / 主动 / ETF（场内）/ ETF 联接（场外买指数）→ 长期 / 定投。</li>
  <li><span class="lab">QDII（投海外）</span>：人民币换外汇买全球；股票 / 债券 / 商品 / REITs 型；「慢、贵、限购、看汇率」→ 配海外。</li>
  <li><span class="lab">FOF（基金中基金）</span>：80% 以上买别的基金；目标日期 / 目标风险；双重收费 + 养老锁定期 → 懒人配置 / 养老。</li>
</ul>

<h2>三、货币基金</h2>
<ul>
  <li><span class="lab">投什么</span>：现金、通知存款、1 年内国债 / 央票、AA+ 以上短融、回购、大额存单；不投股票长期债。监管规定剩余期限 ≤397 天。</li>
  <li><span class="lab">看收益</span>：每万份收益 + 7 日年化（参考值，会浮动，非保收益）。</li>
  <li><span class="lab">风险</span>：极低，非保本但历史极稳；2013 钱荒个别为负（极罕见）。</li>
  <li><span class="lab">费用</span>：无申赎费，管理费 0.15%~0.33% + 托管 0.05% + 销售服务费 0.25%，从收益扣。</li>
  <li><span class="lab">提示</span>：大额别全堆货基；周五 15:00 后买下周一才计息；快赎单日限 1 万。</li>
</ul>

<h2>四、债券基金（含债基风险通俗版）</h2>
<ul>
  <li><span class="lab">债券三兄弟</span>：利率债（国债 / 政策性债，几乎不违约，随利率波动）；信用债（企业债，有违约爆雷风险）；可转债（可转股票，债底 + 股性）。</li>
  <li><span class="lab">细分</span>：纯债（只投债、不碰股，短债≈增强货基、中长债利率敏感）、一级债（旧打新，少见）、二级债（≤20% 股票，固收+ 主力）、可转债基（波动大）。</li>
  <li><span class="lab">收益</span>：纯债年化 3%~5%，二级债 / 固收+ 4%~7%。</li>
</ul>
<div class="box"><span class="k">债基三大风险来源（通俗版）</span>
<p><b>① 利率风险</b>：债券价格和市面利率「反着走」——加息，老债不香→降价。例子：面值 100、付 3% 利息的债，新债付 4% 时，老债要降到 75（3÷75≈4%）才有人买。久期 = 敏感度尺子，久期越长越敏感（价格涨跌≈-久期×利率变动），所以中长债比短债跌得多。</p>
<p><b>② 信用风险</b>：借钱的不还了 = 违约爆雷，本金可能亏。国债几乎不违约，企业债有这风险，低评级更危险但利息高。</p>
<p><b>③ 可转债股性</b>：可转债能转股票，故跟着正股波动，比纯债波动大（有债底托着，通常比股票跌得少）。</p>
<p class="k">一句话：加息→中长债跌（利率）；踩雷→本金亏（信用）；正股崩→可转债部分跌（股性）。</p></div>

<h2>五、混合基金</h2>
<ul>
  <li><span class="lab">是什么</span>：股票 + 债券灵活搭配，股票仓位常 0%~95%（合同设下限）。</li>
  <li><span class="lab">细分</span>：偏股混合（股多、进攻）、偏债混合 / 固收+（债打底 + 少量股，稳）、平衡混合（股债各半）、灵活配置（经理择时）。</li>
  <li><span class="lab">特点</span>：以主动管理为主，业绩高度依赖基金经理。</li>
  <li><span class="lab">风险 / 收益</span>：中~高，取决于股票仓位；管理费约 1%~1.5%/年。</li>
  <li><span class="lab">适合</span> → 想让经理帮忙择时、懒得自己调配股债的人。</li>
  <li><span class="lab">提示</span>：选经理看长期业绩、最大回撤、风格是否稳定，别只看近一年排名。</li>
</ul>

<h2>六、股票基金（指数 / 主动 / ETF / ETF联接）</h2>
<ul>
  <li><span class="lab">是什么</span>：股票仓位 ≥80%，风险高、波动大，适合长期 / 定投。</li>
  <li><span class="lab">被动指数基金</span>：复制指数（沪深300 / 中证500 / A500 / 行业指数），费率低 0.15%~0.5%、持仓透明 → 多数人首选。</li>
  <li><span class="lab">主动股票基金</span>：经理选股求超额，费率高 1.2%~1.5%，可能跑赢也可能跑输。</li>
  <li><span class="lab">ETF</span>：交易型开放式，场内像股票一样实时买卖、费率最低，但<b>需券商账户</b>。</li>
  <li><span class="lab">ETF 联接</span>：场外买 ETF 的基金，方便在支付宝等平台申购，是你买指数的主要方式。</li>
  <li><span class="lab">指数 vs 主动</span>：长期看宽基指数常跑赢多数主动基金（费率低 + 避开幸存者偏差）；主动靠经理能力，需挑人。</li>
</ul>

<h2>七、QDII 基金（含股票型 QDII 与海外指数全解）</h2>

<h3>QDII 总览</h3>
<div class="box">QDII = 用人民币买海外资产的官方通道。国家给外汇额度，基金募人民币换外汇去境外买股 / 债 / 黄金 / REITs，你不用自己换汇、不开境外账户。</div>
<ul>
  <li><span class="lab">细分</span>：股票型（纳指 / 标普 / 恒生科技）、债券型（美债 / 亚洲债）、商品型（原油 / 黄金）、房地产型（海外 REITs）、混合型。</li>
  <li><span class="lab">六大特征（坑）</span>：①时差（T+2 出净值、节假日不同步）②汇率（人民币升贬值直接吃收益）③限额购（热门常停购）④费率高（1.2%~1.8%/年）⑤赎回慢（T+7~T+10）⑥场外不能盘中买卖。</li>
  <li><span class="lab">汇率算例</span>：美股涨 10%、人民币升值 5% → 你只赚约 5%；贬值 5% → 赚约 15%。所以它也是<span class="k">对冲人民币贬值</span>的工具。</li>
  <li><span class="lab">vs 港股通</span>：QDII 买全球、100 元起、支付宝可买；港股通主要投港股、需 50 万门槛（券商端）。</li>
</ul>

<h3>股票型 QDII：被动 vs 主动</h3>
<ul>
  <li><span class="lab">被动（指数型，占多数）</span>：复制海外指数，费率低、透明。买「纳指100 QDII」≈ 一键买那 100 只美国科技股。</li>
  <li><span class="lab">主动（全球股票型）</span>：经理选股，可能超额也可能跑输，费率高。多数人用被动更省心。</li>
</ul>

<h3>海外指数全解（逐个·文字版）</h3>

<h4>纳斯达克100（美国）</h4>
<ul>
  <li><span class="lab">是什么</span>：纳斯达克市值前 100 大非金融股，纯科技成长指数。</li>
  <li><span class="lab">含什么</span>：苹果、微软、英伟达、亚马逊、谷歌、Meta 等，前十大权重常占一半以上。</li>
  <li><span class="lab">特征 / 风险</span>：弹性最大、对利率最敏感（加息时跌得狠），波动极大。</li>
  <li><span class="lab">适合</span> → 押美国科技、能承受 30%+ 回撤的人。</li>
</ul>

<h4>标普500（美国）</h4>
<ul>
  <li><span class="lab">是什么</span>：美国 500 家大型上市公司，覆盖 11 个行业，是「美国股市晴雨表」。</li>
  <li><span class="lab">含什么</span>：科技、金融、医疗、消费、能源全覆盖，比纳指均衡。</li>
  <li><span class="lab">特征 / 风险</span>：最均衡稳健，长期慢牛、波动小于纳指；美股系统性风险。</li>
  <li><span class="lab">适合</span> → 配置美国、长期定投底仓首选。</li>
</ul>

<h4>恒生指数（香港）</h4>
<ul>
  <li><span class="lab">是什么</span>：香港历史最久、最具代表性的蓝筹指数。</li>
  <li><span class="lab">含什么</span>：汇丰、友邦、腾讯、美团、中国移动等，香港市场全貌。</li>
  <li><span class="lab">特征 / 风险</span>：常被视为价值洼地，受内地经济 + 美国利率 + 香港本地三重影响，与 A 股相关但不完全同步。</li>
  <li><span class="lab">适合</span> → 配香港整体、与 A 股互补。</li>
</ul>

<h4>恒生科技（香港）</h4>
<ul>
  <li><span class="lab">是什么</span>：港股上市最大 30 只科技龙头，「港股版纳斯达克」。</li>
  <li><span class="lab">含什么</span>：腾讯、阿里、美团、小米、快手、京东等中国互联网。</li>
  <li><span class="lab">特征 / 风险</span>：高成长高波动，对监管政策（反垄断、数据安全）极敏感。</li>
  <li><span class="lab">适合</span> → 赌中国互联网、能忍波动的人。</li>
</ul>

<h4>德国DAX（德国 / 欧元区）</h4>
<ul>
  <li><span class="lab">是什么</span>：法兰克福 40 只最大蓝筹，欧元区核心指数。</li>
  <li><span class="lab">含什么</span>：宝马、奔驰、西门子、SAP、大众、拜耳等工业制造龙头。</li>
  <li><span class="lab">特征 / 风险</span>：制造业 / 出口属性强、周期性强，受全球工业周期和能源价格影响大（2022 能源危机重挫）。</li>
  <li><span class="lab">适合</span> → 配欧洲工业、与美 / 中资产分散。</li>
</ul>

<h4>日经225 / 东证（日本）</h4>
<ul>
  <li><span class="lab">是什么</span>：日经225 = 225 只龙头（价格加权）；东证 = 全市场（市值加权）。</li>
  <li><span class="lab">含什么</span>：丰田、索尼、软银、迅销（优衣库）、三菱UFJ 等。</li>
  <li><span class="lab">特征 / 风险</span>：近年受日元贬值 + 治理改革推动回暖；<span class="k">关键看日元汇率</span>（区别于美股看美元汇率，日元弱会拖累人民币计价收益）。</li>
  <li><span class="lab">适合</span> → 发达市场多元化配置。</li>
</ul>

<h4>越南 VN30（越南）</h4>
<ul>
  <li><span class="lab">是什么</span>：胡志明交易所 30 只大盘，属前沿市场（比新兴还早期）。</li>
  <li><span class="lab">含什么</span>：银行、地产、消费、券商为主。</li>
  <li><span class="lab">特征 / 风险</span>：高增长潜力，但波动极大、流动性差、涨跌停限制、QDII 额度极少且常停购。</li>
  <li><span class="lab">适合</span> → 仅极小仓位博弹性。</li>
</ul>

<h4>富时100（英国）</h4>
<ul>
  <li><span class="lab">是什么</span>：伦敦证券交易所 100 只最大蓝筹。</li>
  <li><span class="lab">含什么</span>：资源（力拓、壳牌、BP）、金融（汇丰、保诚）、医药（阿斯利康）、消费品（帝亚吉欧）。</li>
  <li><span class="lab">特征 / 风险</span>：成分股约 70%~80% 收入来自海外，英镑走弱常利好；传统高分红；受全球大宗和英镑汇率影响。</li>
  <li><span class="lab">适合</span> → 配英国 / 欧洲、偏好高分红价值股；与 DAX、CAC40 并称欧洲三大。</li>
</ul>

<h4>法国CAC40（法国 / 欧洲）</h4>
<ul>
  <li><span class="lab">是什么</span>：巴黎 40 只蓝筹。</li>
  <li><span class="lab">含什么</span>：奢侈品（LVMH、爱马仕、开云、欧莱雅）、空客、道达尔、巴黎银行等。</li>
  <li><span class="lab">特征 / 风险</span>：奢侈品权重突出，是全球高端消费风向标，对中国消费者信心极敏感；欧元汇率影响大。</li>
  <li><span class="lab">适合</span> → 配欧洲、看好全球消费 / 奢侈品龙头。</li>
</ul>

<h4>印度 Nifty50 / Sensex（印度）</h4>
<ul>
  <li><span class="lab">是什么</span>：印度两大旗舰指数（国家所 50 只 / 孟买 30 只）。</li>
  <li><span class="lab">含什么</span>：IT 服务（TCS、Infosys）、金融（ICICI、HDFC）、消费、信实等。</li>
  <li><span class="lab">特征 / 风险</span>：高增长但估值偏高、由外资流向驱动；<span class="k">卢比波动大、印度 QDII 极少</span>（多靠亚太 / 新兴组合间接配）。</li>
  <li><span class="lab">适合</span> → 小仓位长期看印度增长。</li>
</ul>

<h4>MSCI 新兴市场（多国）</h4>
<ul>
  <li><span class="lab">是什么</span>：覆盖约 24 个新兴市场国家 / 地区的大中盘，最常用「新兴市」基准。</li>
  <li><span class="lab">含什么</span>：中国（权重常占三成）、印度、韩国、巴西、台湾、南非等。</li>
  <li><span class="lab">特征 / 风险</span>：一篮子分散单一国风险，但走势很大程度被中国主导；美元走强时整体承压。</li>
  <li><span class="lab">适合</span> → 想「一键买一篮子新兴国家」、求广不求锐。</li>
</ul>

<h4>MSCI 全球 / 全球股票（全球）</h4>
<ul>
  <li><span class="lab">是什么</span>：MSCI World = 23 个发达国家；MSCI ACWI = 全球（发达 + 新兴）约 47 国，覆盖最广。</li>
  <li><span class="lab">含什么</span>：美国（World 里占六成以上）、日、英、法、德等；ACWI 再加中印等新兴。</li>
  <li><span class="lab">特征 / 风险</span>：最分散、弹性最小、最「稳」，但本质大半是美股，仍受美国主导。</li>
  <li><span class="lab">适合</span> → 全球配置压舱石、懒人全球定投。</li>
</ul>

<h2>八、FOF 基金</h2>
<ul>
  <li><span class="lab">是什么</span>：基金资产 80% 以上买其他公募基金，帮你做配置。</li>
  <li><span class="lab">细分</span>：股票型 / 债券型 / 混合型 FOF；养老目标 FOF（目标日期如「养老2045」随退休日降仓位；目标风险如稳健 / 平衡 / 积极）。</li>
  <li><span class="lab">特点</span>：双重收费（FOF 一层 + 底层一层，部分内部 FOF 减免）、专业分散、波动小于单只股基；养老 FOF 多带锁定期（1 / 3 / 5 年）。</li>
  <li><span class="lab">适合</span> → 懒人配置、养老储备、不擅长选基；买前看是否双重收费、锁定期、业绩基准。</li>
</ul>

<h2>九、补充品种：ETF / LOF / REITs / 场内vs场外</h2>
<ul>
  <li><span class="lab">ETF（交易型开放式指数基金）</span>：场内实时交易、费率极低、跟踪指数、一篮子股票。需券商账户，盘中买卖。你是场外支付宝买，主要用它的「ETF 联接」。</li>
  <li><span class="lab">LOF（上市型开放式基金）</span>：既能场内交易也能场外申赎，还能「转托管」打通两边。</li>
  <li><span class="lab">公募 REITs</span>：投基础设施（高速 / 产业园 / 仓储物流 / 污水处理），强制高比例分红，风险收益介于股债之间。</li>
  <li><span class="lab">封闭式基金</span>：有固定封闭期，到期前不能赎回，只能场内折价 / 溢价买卖。</li>
  <li><span class="lab">场外 vs 场内</span>：<span class="k">场外</span>=支付宝 / 银行 / 基金公司 APP 按当日净值申赎（你用的），门槛低、品种全、一天一个价；<span class="k">场内</span>=券商账户像股票一样实时买卖，费率低、可盘中操作，但需开户。</li>
</ul>

<h2>十、投资方向：宽基 / 行业 / 主题 / 因子</h2>
<div class="box"><span class="k">记住</span>：<b>类型</b>是「买什么大类」，<b>方向</b>是「具体押哪条线」。一只「股票基金」是类型，它是「医药」还是「红利低波」是方向。</div>

<h3>宽基（不押行业，求稳底仓）</h3>
<ul>
  <li><span class="lab">沪深300</span>：两市 300 只大盘蓝筹（茅台 / 宁德 / 平安），A 股基准，定投底仓首选。</li>
  <li><span class="lab">中证500</span>：剔除 300 后的 500 只中盘，弹性比 300 大，互补。</li>
  <li><span class="lab">中证A500</span>：2024 新宽基，行业更均衡接近全市场，新晋均衡底仓。</li>
  <li><span class="lab">创业板指</span>：100 只创业板成长股（宁德 / 东财 / 迈瑞），高成长高波动。</li>
  <li class="sub">其他：上证50（沪市超大盘）、中证1000（小盘）、科创50（硬科技）。</li>
</ul>

<h3>行业（押单一赛道，波动大）</h3>
<ul>
  <li><span class="lab">消费</span>：白酒 / 家电为主，长牛但估值高位回撤大。</li>
  <li><span class="lab">医药</span>：制药 / CXO / 器械，刚需创新但受集采政策打压。</li>
  <li><span class="lab">科技</span>：电子 / 计算机 / 互联网，高弹性、怕制裁和估值泡沫。</li>
  <li><span class="lab">新能源</span>：光伏 / 锂电 / 车，高景气但强周期、2022 后深度回调。</li>
  <li><span class="lab">半导体</span>：国产替代核心，高弹性、怕外部制裁和周期。</li>
  <li><span class="lab">军工</span>：逆周期、事件驱动，信息不透明、主题炒作重。</li>
</ul>

<h3>主题（押风口，退潮快）</h3>
<ul>
  <li><span class="lab">人工智能 AI</span>：算力 / 大模型，最强风口但概念炒作重、业绩未兑现。</li>
  <li><span class="lab">碳中和</span>：新能源 + 绿电，与新能源高度重叠。</li>
  <li><span class="lab">机器人</span>：产业化早期、想象大但极高风险。</li>
</ul>

<h3>风格 / 因子</h3>
<ul>
  <li><span class="lab">红利（高股息）</span>：挑分红多、股息率高的股票，熊市抗跌吃分红。</li>
  <li><span class="lab">低波（低波动）</span>：挑股价波动小的股票，回撤小。</li>
  <li><span class="lab">红利低波（双因子）</span>：高股息 + 低波动叠加，防御性强，属 Smart Beta；代表指数中证红利低波动 930955、红利低波100 930716 → 适合稳健、长期定投。</li>
  <li><span class="lab">价值 / 成长 / 质量 / 动量 / 大盘 / 中小盘</span>：不同选股维度。</li>
</ul>

<h2>十一、怎么从名称看类型</h2>
<p>命名公式 = <b>管理人</b> ＋ <b>特征/方向</b> ＋ <b>类型词</b> ＋ <b>份额字母</b>。例：<code>易方达 蓝筹精选 混合 A</code>。看类型抓「类型词」和「末尾字母」最准。</p>
<ul>
  <li><span class="lab">类型词速查</span>：货币 / 现金 / 宝 → 货币；债券 / 纯债 / 中短债 / 信用债 / 可转债 → 债券；混合 / 灵活配置 → 混合；股票 → 股票（主动）；指数 / ETF联接 / 中证XXX / 沪深300 → 指数；ETF（场内）→ 交易型；QDII → 海外；FOF → 基金中基金；养老 → 养老目标 FOF；REITs → 基础设施 REITs；量化 → 量化基金。</li>
  <li><span class="lab">特征词看方向</span>：红利 / 低波 / 价值 / 成长 / 蓝筹 / 中小盘 / 医药 / 消费 / 科技 / 新能源 / 半导体 / 军工 / 沪港深 / 增强 / 联接。</li>
  <li><span class="lab">命名陷阱</span>：「稳健 / 安心 / 丰禄 / 添利」是营销词不保本；名字带行业 ≠ 满仓；「养老」有波动和锁定期；「QDII」不一定是股票（还有债基 / 黄金 / REITs）。</li>
  <li><span class="lab">实战解码</span>：<code>招商中证红利低波动ETF联接C</code> → 红利低波指数（场外）短期选 C；<code>华夏纳斯达克100ETF联接(QDII)A</code> → 海外科技、受汇率 + 限购；<code>工银瑞信养老2045(FOF)Y</code> → 养老目标日期 FOF，仅养老金账户；<code>鹏华丰禄债券</code> → 债券；<code>中欧医疗健康混合A</code> → 医疗主题混合（波动大）。</li>
  <li><span class="lab">支付宝确认三步</span>：①名称初步判断；②点进看顶部「基金类型」标签（官方最准）；③看「跟踪标的」是否指数、「资产配置」股债占比。</li>
</ul>

<h2>十二、场外基金费用（每天从净值里悄悄扣）</h2>
<table>
  <tr><th>费用</th><th>谁收</th><th>怎么收</th><th>备注</th></tr>
  <tr><td>申购费</td><td>销售平台</td><td>买入一次性收（A 收、C 免）</td><td>支付宝常打 1 折</td></tr>
  <tr><td>赎回费</td><td>基金公司</td><td>卖出收，持有越短越高</td><td>&gt;7天 / &gt;30天递减，长期常免；短期或收 1.5%</td></tr>

  <tr><td>管理费</td><td>基金公司</td><td>所有份额按日扣</td><td>年化 0.15%~1.5%（QDII / 主动偏高）</td></tr>
  <tr><td>托管费</td><td>托管银行</td><td>所有份额按日扣</td><td>年化 0.05%~0.25%</td></tr>

<h2>十三、常见名词速查</h2>
<ul>
  <li><span class="lab">单位净值</span>：一份基金值多少钱，你买卖按它算。<span class="lab">累计净值</span>：加上历史分红后的净值。</li>
  <li><span class="lab">定投</span>：固定时间投固定金额，自动摊平成本，适合波动大的股票 / 指数基金。</li>
  <li><span class="lab">最大回撤</span>：历史上从最高点到最低点跌了多少，衡量「最惨能亏多少」。</li>
  <li><span class="lab">波动率</span>：净值上下起伏的剧烈程度，越大越刺激也越难拿住。</li>
  <li><span class="lab">跟踪误差</span>：指数基金和它跟踪的指数之间的偏离，越小越好。</li>
  <li><span class="lab">业绩比较基准</span>：基金的「及格线」，跑赢它才算合格。</li>
  <li><span class="lab">重仓股 / 行业集中度</span>：前十大持仓占多少，越高越集中、波动越大。</li>
  <li><span class="lab">现金分红 / 红利再投资</span>：分红拿现金，还是自动再买成份额（长期复利选再投资）。</li>
  <li><span class="lab">封闭期 / 锁定期</span>：这段时间不能赎回（养老 FOF 常见 1 / 3 / 5 年）。</li>
  <li><span class="lab">限购 / 大额限购</span>：暂停买入或限制单日金额，QDII 常见。</li>
  <li><span class="lab">T+1 / T+2</span>：T 是交易日，T+1 即下一个工作日确认或到账。</li>
  <li><span class="lab">清盘风险</span>：基金规模太小（如连续低于 5000 万）可能被强制清盘，选基金避开迷你基。</li>
</ul>

<h2>十四、支付宝实操与配置口诀</h2>
<ul>
  <li>长期定投 → 优先 <span class="k">A 类</span>；试水 / 拿不准 → 用 <span class="k">C 类</span>。</li>
  <li>活钱 / 备用金放 <span class="k">货基</span>；半年以上稳健放 <span class="k">债基 / 固收+</span>；长期增值用 <span class="k">宽基指数</span>。</li>
  <li>稳健现金流 → 关注 <span class="k">红利低波</span>；配海外 → 用 <span class="k">QDII</span>（接受慢 + 贵 + 限购 + 汇率）；懒人 / 养老 → 看 <span class="k">FOF</span>（留意双重收费与锁定期）。</li>
  <li>买前必看四项：<span class="k">基金类型标签、跟踪标的、费率详情、持仓 / 行业分布</span>。</li>
  <li>避开：名字花哨但类型词模糊的、规模过小的迷你基、短期排名冲得很猛的。</li>
</ul>
<div class="note"><b>总口诀</b><br>
<span class="k">份额</span>：长拿 A、短炒 C；I 机构价、D 直销价、Y 养老金。<br>
<span class="k">方向</span>：宽基做底仓、行业做增强、主题做卫星。<br>
<span class="k">配置</span>：用沪深300 / 中证A500 / 标普500 打底，1~2 个看好行业加弹性，主题只放极小仓位博风口。<br>
<span class="k">风险</span>：货币≈无波动；债基有利率 / 信用 / 股性三风险；QDII 背「慢贵限购看汇率」四件套；海外同样会大跌、不保本。<br>
<span class="k">心态</span>：先看懂再买，费率是长期复利的隐形杀手，不懂的品种不碰。</div>
